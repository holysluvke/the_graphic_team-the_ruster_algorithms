# the_graphic_team-the_ruster_algorithms
лабораторная работа #3 по дисциплине «Компьютерная графика». тема: «Растровые алгоритмы». команда «Графические»

## Запуск
```
pip install -r requirements.txt
python main.py
```

## Структура
- `main.py` — главное окно с вкладками; места для заданий 2 и 3 помечены `TODO`.
- `task1.py` — задание 1: заливка сериями пикселов (1а — цветом, 1б — рисунком) и обход границы (1в).
- `patterns/` — примеры рисунков для 1б: `small_pattern.png` (40×40, повторяется циклически)
  и `big_pattern.png` (1000×700, больше холста — берётся напрямую).

## Задание 1 — как пользоваться
1. Режим «Рисование области»: нарисовать мышкой замкнутую область (можно с отверстиями внутри)
   или нажать «Пример области с отверстиями».
2. 1а: выбрать режим «заливка цветом» и щёлкнуть внутри области.
3. 1б: «Загрузить рисунок...», затем щёлкнуть внутри области.
4. 1в: при необходимости «Загрузить изображение...», выбрать режим «выделение границы» и щёлкнуть
   внутри области. Начальная точка — первый пиксел другого цвета справа от щелчка; найденная
   граница рисуется поверх изображения, список точек можно сохранить в файл.
